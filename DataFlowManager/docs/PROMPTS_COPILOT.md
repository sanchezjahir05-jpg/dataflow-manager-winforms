# Uso de GitHub Copilot y Prompt Engineering

## Prompt 1

Crea una clase Trabajador en C# con cédula, nombre, apellido, ciudad y cargo.

## Prompt 2

Crea una clase Incidencia en C# que tenga ID, título, descripción, responsable, prioridad, estado, fecha de creación y fecha límite.

## Prompt 3

Crea un controlador en C# para administrar una lista de incidencias con métodos agregar, editar, eliminar, buscar y listar.

## Prompt 4

Genera código para cargar una lista de objetos en un DataGridView en Windows Forms.

## Prompt 5

Crea un archivo GitHub Actions para compilar automáticamente un proyecto C# de Windows Forms.

## Análisis

GitHub Copilot fue utilizado como herramienta de apoyo para generar ideas de código, estructuras base y automatización. Sin embargo, el código fue revisado, corregido y adaptado manualmente según las necesidades del proyecto.
