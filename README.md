# DataFlow Manager

Sistema de gestión de tareas e incidencias desarrollado en C# con Windows Forms para una empresa de desarrollo de software.

## Objetivo del proyecto

Simular una solución tecnológica que permita mejorar la organización del trabajo, el control de incidencias, la asignación de responsables y el seguimiento de tareas dentro de una empresa de software.

## Problema que resuelve

La empresa presenta pérdida de versiones del código, falta de organización en el equipo, errores frecuentes en producción, falta de documentación técnica y ausencia de herramientas modernas de automatización.

## Funcionalidades principales

- Registro de incidencias.
- Asignación de responsable.
- Gestión de trabajadores.
- Clasificación por prioridad.
- Clasificación por estado.
- Edición de incidencias.
- Eliminación de incidencias.
- Búsqueda de incidencias.
- Visualización de datos en DataGridView.
- Dashboard de resumen.
- Formulario informativo del proyecto.

## Tecnologías utilizadas

- C#
- Windows Forms
- Visual Studio
- Git
- GitHub
- GitHub Actions
- GitHub Copilot
- Spec Driven Development
